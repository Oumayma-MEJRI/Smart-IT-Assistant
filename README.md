# Smart IT Assistant Pro

Application de diagnostic et d’assistance informatique développée en Python.

## Présentation

Smart IT Assistant Pro est un projet personnel conçu pour faciliter les premiers diagnostics d’un ordinateur Windows.

L’application permet de consulter les ressources du système, de détecter certaines situations nécessitant une attention particulière et de proposer des recommandations simples.

## Fonctionnalités

* Consultation des informations du système.
* Analyse de l’utilisation du processeur (CPU).
* Vérification de la mémoire vive (RAM).
* Analyse de l’espace disque.
* Test de la connexion Internet.
* Affichage d’alertes et de recommandations.
* Enregistrement d’un rapport de diagnostic.

## Technologies utilisées

* Python : développement de l’application.
* Tkinter : création de l’interface graphique.
* psutil : récupération des informations système.
* PyInstaller : création d’une application Windows (.exe).
* GitHub : publication et présentation du projet.

## Objectif du projet

Mettre en pratique des compétences en diagnostic informatique, en programmation Python et en résolution de problèmes techniques.

Ce projet s’inscrit dans une démarche d’apprentissage des métiers du support informatique.

## Développement

Projet réalisé dans le cadre d’un apprentissage personnel, avec l’aide d’outils d’intelligence artificielle pour améliorer et structurer certaines parties du programme.

## Évolutions prévues

* Amélioration de l’interface graphique.
* Ajout de nouvelles fonctionnalités de diagnostic.
* Tests sur différents ordinateurs Windows.
